# Personal Expense Tracker

A console-based Personal Expense Tracker built using Python.

This project demonstrates the practical application of Python programming, Object-Oriented Programming (OOP), CRUD operations, JSON data persistence, exception handling, input validation, and modular project architecture.

The application allows users to manage personal expenses efficiently through a simple command-line interface while maintaining expense data permanently using JSON file storage.

---

## Features

- Add new expenses
- View all recorded expenses
- Search expenses by category
- Calculate total expenses
- Find the highest expense
- Update existing expenses
- Delete expenses
- Persistent data storage using JSON
- Input validation
- Exception handling
- Object-Oriented Programming
- Modular multi-file architecture

---

## Technologies Used

- **Python 3**
- **JSON**
- **Object-Oriented Programming (OOP)**
- **File Handling**
- **Exception Handling**
